# Well Speed Logistics India

A premium freight and logistics website for Well Speed Logistics India — Mumbai-based transport partner for trucks, containers, trailers, and ODC cargo across India.

## 🚛 About

Well Speed Logistics India provides reliable freight solutions from 14 FT tempos to 40 FT trailers. This website serves as the company's digital presence, allowing customers to browse fleet options, understand services, and book vehicles via WhatsApp.

## ✨ Features

- **Responsive Design** — Works seamlessly on mobile, tablet, and desktop
- **Fleet Showcase** — Six vehicle categories with detailed descriptions
- **Interactive Booking Form** — Sends booking requests directly to WhatsApp
- **Cities We Serve** — Pan-India network coverage
- **FAQ Section** — Common questions answered for customers
- **Premium Typography** — Royal Purple + Champagne Gold color scheme

## 🛠 Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, Flexbox, Grid
- **Vanilla JavaScript** — No frameworks, lightweight
- **Google Fonts** — Cormorant Garamond + Outfit
- **GitHub Pages** — Free static hosting
